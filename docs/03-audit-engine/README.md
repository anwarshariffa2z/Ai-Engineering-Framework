# Audit Engine Documentation

## Purpose

Provide the ordered document structure for the Audit Engine.

## Scope

This directory contains ten approved discovery and verification methodologies, AUD-0002 through AUD-0011, and one draft structural placeholder, AUD-0001 Bootstrap. It contains no implementation. The artifact types these methodologies produce and consume are declared under `docs/10-artifact-types/`, and their composition into an audit is governed by [CAP-0001](../09-capabilities/CAP-0001-repository-audit.md).
