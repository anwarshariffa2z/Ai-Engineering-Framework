# Documentation Navigation

The [Document Registry](DOCUMENT_INDEX.md) is the canonical inventory. The numbered folders are stable information domains: foundation, methodology, Audit Engine, development, reference, governance, roadmap, and examples. [Architecture Decision Records](ADR/README.md) retain a dedicated stable location.

The documents use `MUST`, `SHOULD`, and `MAY` in their conventional normative sense: mandatory, recommended except with a documented reason, and optional.
