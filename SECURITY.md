# Security Policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub’s private vulnerability reporting for this repository, including the affected files or documents, reproduction steps, impact, and any suggested mitigation.

Maintainers will acknowledge reports, assess severity and reachability, coordinate remediation, and publish an advisory when disclosure is appropriate. The framework’s security guidance is in [Security Standard](docs/04-development/security-standard.md).

## Scope

Security reports may cover repository automation, supplied examples, and framework guidance that could plausibly lead teams to unsafe implementations. The framework itself does not currently operate production services or process user data.
